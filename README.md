# Calculadora Python 1.0 🧮

Minha primeira calculadora desenvolvida em Python durante meus estudos de programação.

## 📌 Sobre o projeto

Este projeto foi criado para praticar conceitos básicos de Python e entender como cada estrutura funciona na prática.

## ⚙️ Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Validação de opções do menu
- Tratamento de divisão por zero
- Repetição de operações
- Opção para encerrar a calculadora

## 📚 Conceitos praticados

- Variáveis
- `input()`
- Conversão de dados com `int()` e `float()`
- `if` e `elif`
- `while`
- `for`
- `range()`
- Listas
- Operadores matemáticos
- Índices de listas

## ▶️ Como executar

É necessário ter o Python instalado.

Depois de clonar o repositório, execute:

```bash
python calculadora.py
--------------------------------------

## 🚧 Limitações da versão 1.0

 Esta é a primeira versão da calculadora e foi desenvolvida principalmente como uma forma de colocar em prática os conceitos que estou aprendendo em Python.

Por enquanto, a calculadora trabalha apenas com dois números por operação e ainda não possui tratamento para entradas que não sejam numéricas, como letras ou caracteres inválidos.

Essas limitações fazem parte do projeto neste momento e serão trabalhadas nas próximas versões conforme eu aprender novos conceitos e aprimorar minhas habilidades em programação.

## 🎯 Objetivo do projeto

O objetivo desta calculadora não foi criar um sistema avançado, mas sim praticar programação, testar meus conhecimentos e entender na prática como cada estrutura do Python funciona.

A versão 1.0 representa uma das primeiras etapas da minha evolução estudando programação.

Pretendo continuar desenvolvendo o projeto e criar novas versões conforme meu aprendizado, adicionando novas funcionalidades, melhorias e soluções para os problemas encontrados nesta primeira versão.
